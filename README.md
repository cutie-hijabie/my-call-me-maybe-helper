# Call Me Maybe — Learning Resources

My personal collection of notes, resources, and documentation while working on **Call Me Maybe** at 42.

This repository is for people who **want to learn**, not people looking for the finished answer.

Think of it as a map, not a solution.

---

## 📖 System Overview

The repository contains a PDF with a high-level overview of the project and how its different parts fit together.

I use it as a reference while working, but I don't follow it exactly. It's there to help with perspective and understanding, not as a strict guide.

---

## 📝 Notes

`notes.md` contains things I've learned throughout the project, along with explanations, observations, and useful resources.

It's mainly a place to keep things that helped me understand the project and that I may want to come back to later.

## 📅 Daily Progress

This repository is updated **day by day** as I work on Call Me Maybe.

Each work session may have its own `.md` file containing a short summary of what I worked on, what I learned, and things that may be useful to someone working through the same project.

The repository is a **work in progress** and will continue to change as I progress through the project.

These are **not** a walkthrough — they're a record of the messy, real process of figuring things out.

## 🚫 What You Won't Find Here

I won't be documenting the complete implementation or giving away the exact solutions.

Some things will intentionally be left vague so that you still have to:

* Research.
* Read documentation.
* Understand the concepts.
* Make your own implementation decisions.
* Debug your own code.

If you're looking for something to copy, this probably isn't the right repository.

If you're looking for something to help you get **unstuck and understand where to look**, hopefully it is.

---

## ⚠️ Keep in Mind

This is **my approach** to the project, not the only approach.

Things may change as I learn more, and some notes may eventually be updated or corrected.

Don't blindly follow anything here — use it as a starting point and verify things for yourself.
